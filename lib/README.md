# 📊 Calculate GPA - Flutter Mobile Application

A modern, minimalist, and user-friendly **University Grade Point Average (GPA) Calculator** mobile application. Developed using Flutter and Dart, following Material 3 design standards with robust dynamic form validation.

## ✨ Features

* **Real-time GPA Calculation:** The overall GPA updates instantly as courses are added or deleted, dynamically calculating letter grade weights and credits.
* **Smart Form Validation:** Clear, dynamic error messages guide the user if they attempt to submit with empty fields, ensuring type safety.
* **Enhanced UX Touches:** Text styles and colors switch dynamically once a selection is made, providing clear visual feedback.
* **Swipe-to-Delete (Dismissible):** Users can seamlessly swipe left or right on any course card to remove it from the list with a smooth animation.
* **Reverse Chronological Order:** Newly added courses are inserted at the very top of the list for better visibility.

## 🛠️ Technologies & Architecture

* **Framework:** Flutter (Dart)
* **State Management:** StatefulWidget & `setState`
* **UI Components:** TextFormField, DropdownButtonFormField, Dismissible, ListView.builder, Card, ListTile
* **Design & Typography:** Material 3 Standards & Custom Fonts (Poppins)
